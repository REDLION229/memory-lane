# my-data

Put your unzipped Google Takeout YouTube files here. Subfolders are fine, for example:

```
my-data/
  comments/      comments.csv, comments(1).csv, ...
  live-chats/    live chats.csv, ...
  messages/      conversation_*.csv
  uploads/       video texts.csv
  history/       watch-history.html (or .json)
```

Everything in this folder except this README is ignored by git, so your data never gets uploaded.
